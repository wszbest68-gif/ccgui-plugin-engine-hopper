# 引擎接力（engine-hopper）

CC GUI 插件：在**同一对话**中随时切换引擎与模型——自动整理完整对话上下文、智能分层交接，新引擎无缝续聊。

## 功能

- **一键接力**：输入框状态行「⇄ 接力」芯片选择目标引擎与模型，当前对话（含接力链全部历史）自动整理后交给新引擎继续。
- **智能分层**：近期对话原文保留，早期对话首尾压缩；超预算时逐级降级（压缩 → 省略最早 → 截断），保证不爆目标引擎上下文。
- **接力链**：每次接力记入链式账本（右侧面板「切换引擎/模型」页签可视）。切回去过的引擎时可「续接既有会话」——只补增量上下文；无增量则零消耗直接跳回。档位（effort）随链携带。
- **透明过滤**：引擎内部的 thinking/tool 记录不进交接，但会在交接消息中计数标注。
- **命令**：命令面板「跳回接力链上一会话」「打开设置」。

## 使用

1. 打开任意有内容的会话，点输入框状态行「⇄ 接力」。
2. 选目标引擎与模型（留空 = 引擎默认模型），选交接方式（智能分层 / 全文）。
3. 「开始接力」→ 自动跳转到新会话，目标引擎先确认「进展 / 待办 / 约束」，随后继续原任务。

同引擎只换模型不需要接力——宿主输入框上方选择器原生支持且历史连续。

## 数据边界（隐私）

- 对话内容只在**本地**读取（宿主 `app.db` 统一消息表，只读）与拼接，经宿主引擎管线发送给**你自己选择的目标引擎**。
- 本插件**不发起任何网络请求**（无 `network` 权限）。

## 权限清单与用途

| 权限 | 用途 |
|---|---|
| `storage` | 接力链账本与设置（每插件隔离 KV） |
| `events` | 跟踪当前会话（`session://activated`）与生成状态（`usage://*`） |
| `host:session` | 接力后跳转会话、刷新侧栏、携带 effort 档位 |
| `host:models` | 枚举宿主已启用引擎与模型目录 |
| `agent` | 经宿主引擎管线在目标引擎开/续会话并注入交接上下文 |
| `exec:node` | 内嵌只读 helper（node:sqlite 读 app.db），无任何写操作 |
| `ui:composer-status` / `ui:panel-tab` / `ui:settings-section` / `ui:command` / `ui:status-bar` | 对应 UI 扩展点 |
| `i18n` | 中英文界面资源 |

## 安装

CC GUI → 插件 → 市场搜索「引擎接力」，或「从本地目录安装」选择本仓库根目录（含 `manifest.json` 一层）。要求宿主 ≥ 1.0.10（SDK ^0.3.16）。
